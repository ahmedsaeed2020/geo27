- __root.tsx splits paths with isCorePath(): website paths keep site.css, the CMS loader and Lovable Cloud auth; DIGIT Core app paths lazy-load coreRoot/coreHead with src/styles.css and the enterprise sheets, so neither side's styles or data loading leak into the other.
- DIGIT Core sign-in (/login) accepts only site admin accounts verified on the server and issues an httpOnly cookie signed with the DIGIT_CORE_SESSION_KEY secret (src/lib/siteAuth.server.ts); /api/assistant requires that cookie, so no credential or signing key lives in source and visitors cannot spend AI requests.
- Pro, HR, Construction and FSM apps are switched off in this build (coreBeforeLoad redirects them to /digit-crm/home); their files carry a `@ts-nocheck` marker because their original /pro/* and /hr/* app routes belong to the website here, and classic /crm/* CRM links point at /digit-crm or desk screens.
